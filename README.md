# VR 播放器

一个完全本地自托管的 VR / 360° 视频播放器：无需上传、无需联网服务，打开浏览器就能播放**本地视频文件**和**在线视频直链**，默认进入 VR / 360° 沉浸视图。

## 功能特性

- **两种片源**
  - 📁 本地文件：点击「打开本地文件 / 打开文件夹」或直接把视频拖进页面
  - 🔗 在线直链：粘贴 http(s) 视频地址，点「播放链接」或回车
- **播放列表**：多选文件或选择文件夹后自动生成列表（按文件名自然排序；打开文件夹时自动排除 50MB 以下的小文件），支持上一集 / 下一集、列表面板点选、播完自动连播；兼容 PotPlayer 的 **.dpl 播放列表文件**（自动识别 UTF-8 / GBK 编码），并采用**渐进式本地授权**：
  - 导入 dpl 即完整展示列表：在线条目标「在线」可直接播；本地条目标「未授权」，不遮挡画面、不报错
  - 点未授权条目即可单独选择对应文件授权（优先系统文件选择器，校验文件名一致才绑定）
  - 「添加媒体目录」选择视频所在文件夹后，按**路径后缀唯一匹配 > 文件名唯一匹配 > 同名冲突（提示手动选择，不静默乱绑）**自动匹配；「重新匹配」可对未解析条目再来一轮
  - 条目角标区分 本地 / 在线 / 未授权 / 未找到 / 同名冲突；播完自动连播遇到未授权条目会停下并打开面板引导授权
  - 隐私：本地文件仅在浏览器内读取，不会上传服务器（刷新页面后授权失效，重新点选即可）
- **VR / 360° 默认视图**：加载后自动进入全景模式，拖动旋转视角、滚轮缩放视场角（FOV），可一键切回普通平面模式
- **SBS 左右分屏支持**：自动检测超宽画幅（宽高比 > 2.5），提供 仅左眼 / 仅右眼 / 左右分屏 三种观看模式
- **内置跨域代理**：`/proxy` 接口转发在线视频（带 Range 断点续传、自动跟随 302 跳转），没有 CORS 头的视频站也能在 VR（WebGL 纹理）模式下播放
- **完整播放控制**：播放/暂停、进度条拖动、音量、0.25x–2x 倍速、全屏、空格快捷键
- **服务器实时转码**：手机解不了 8K HEVC 时，可一键由服务器 ffmpeg 转成 4K H.264 HLS 流（iPhone Safari 原生支持，可拖动进度）。macOS 自动使用 VideoToolbox，Linux 使用 libx264；能否达到实时速度取决于片源参数和服务器性能，空闲 2 分钟后自动停止
- **编码错误友好提示**：遇到 MKV / HEVC / AC3 等浏览器不支持的格式时给出转码命令建议
- **纯净无广告**：不含任何广告

## 快速开始

零依赖，只需要本机装有 Node.js：

```bash
# 方式一：npm
npm run dev

# 方式二：直接运行
node server.js

# 方式三（macOS）：双击「启动 VR 播放器.command」
```

然后在浏览器打开 <http://localhost:7100/>。

### 桌面版（Electron，Windows / macOS）

桌面版在网页版全部能力之上，额外提供 **DPL 播放列表直读**：dpl 里的本地绝对路径由系统直接查磁盘，存在即可流式播放（支持拖动进度），不需要在浏览器里逐个授权。

```bash
npm install        # 首次，安装 electron
npm run desktop    # 启动桌面窗口
```

打包安装包（需本机已装 Node）：

```bash
npm run dist       # 输出到 dist/（macOS 出 .dmg，Windows 出 NSIS 安装包）
```

> 桌面版内嵌同一个 `server.js`（仅监听 127.0.0.1 随机端口），代理、编码探测、服务器转码与网页版完全一致；本地文件通过 `--local-fs` 开启的 `/local` 接口流式读取，该开关仅桌面端启用。
> Windows 播放 HEVC 需要系统安装「HEVC 视频扩展」；macOS 原生支持。

指定地址和端口：

```bash
node server.js --host 127.0.0.1 --port 8080
# 也支持 --host=127.0.0.1 --port=8080 写法
```

> 当 host 为 `localhost` 时，服务器会绑定双栈地址，`127.0.0.1` 和 `localhost`（IPv6）都能访问。

## 使用说明

| 操作 | 说明 |
| --- | --- |
| 播放本地视频 | 中央面板点「打开本地文件 / 打开文件夹」，或把文件（可多选）拖进页面 |
| 导入 dpl 列表 | 把 PotPlayer 的 .dpl 文件拖进页面或随文件一起选择；在线条目直接可播，本地条目显示「未授权」，点条目单独授权或点「添加媒体目录」自动匹配 |
| 播放列表 | 控制栏「列表」图标打开面板，点条目切换；⏮ / ⏭ 切换上下集，播完自动下一集（遇未授权条目会停下并提示授权） |
| 播放在线视频 | 中央面板粘贴视频直链 →「播放链接」/ 回车 |
| 切换视图 | 顶栏「普通模式」/「VR / 360」 |
| VR 视角 | 鼠标拖动旋转，滚轮缩放 |
| 换一部视频 | 顶栏「打开新视频」，可从「返回播放」回到当前视频 |
| 快捷键 | 空格 = 播放 / 暂停 |

## 在线直链的工作原理

浏览器出于安全限制（CORS、混合内容、WebGL 纹理污染）通常不能直接跨域播放视频。本项目的 `server.js` 内置了 `/proxy?url=<地址>` 接口：

- 转发客户端的 `Range` 头，支持进度条拖动和分段加载
- 自动跟随 301/302/303/307/308 重定向（最多 5 次）
- 把 `application/octet-stream` 修正为 `video/mp4`

页面上所有跨域链接都会自动改走这个代理，对使用无感知。

## 浏览器兼容性

| 浏览器 | 说明 |
| --- | --- |
| Safari | 推荐。对 HEVC / H.265 支持最好 |
| Safari (iPhone / iPad) | 已适配移动端界面，视频内联播放（`playsinline`），不会跳转系统播放器；音量和全屏由系统控制 |
| Chrome / Edge | H.264 + AAC 的 MP4 完美支持；**HEVC 大多无法解码**，会提示转码 |
| Firefox | 同 Chrome，不支持 HEVC |

遇到不支持的格式，可用 FFmpeg 转码：

```bash
ffmpeg -i input.mkv -c:v libx264 -c:a aac output.mp4
```

## 已知限制

- **iPhone / iPad 播放 SMB 网络位置的文件**：iOS「文件」App 对 SMB 共享采用占位文件机制，选中后系统必须先把**整个文件复制到 Safari 沙盒**才能交给网页——几十 GB 的视频会在后台无声下载很久甚至失败（表现为选择后没反应）。建议：① 在「文件」App 里长按视频 →「下载」或拷贝到「我的 iPhone」后再选择；② 更推荐直接粘贴视频的在线直链播放（配合服务器转码，手机也能看 8K HEVC）。播放器已对此加了 0 字节拦截、读取超时提示和明确的操作指引。
- **网盘签名直链**（如 115、阿里云盘等）通常绑定生成时的 IP / 登录态，换网络环境会报 `invalid signature`，需要在当前网络下重新复制链接，或先下载到本地再播放。
- 有声视频首次播放可能被浏览器自动播放策略拦截，点一下播放键即可。
- 超大（8K+）视频能否流畅播放取决于本机硬解能力。

## 技术栈

- 零依赖 Node.js 静态服务器（`server.js`，含视频代理）
- [Three.js](https://threejs.org)（已内置于 `vendor/`）渲染 360° 球体纹理
- 原生 HTML5 `<video>` + WebGL，无任何构建步骤

## 目录结构

```
vr-player/
├── index.html            # 播放器页面（样式 + 全部交互逻辑）
├── server.js             # 本地服务器 + /proxy 视频代理
├── package.json          # npm run dev 入口
├── vendor/               # three.js、图标字体（全部本地化）
├── favicon.svg
├── background-pic.jpg    # og:image 分享图
└── 启动 VR 播放器.command # macOS 双击启动脚本
```

## 隐私

所有处理都在本机完成：本地文件通过 `URL.createObjectURL` 直接读取，不会上传到任何服务器；在线链接只经过本机代理转发。
